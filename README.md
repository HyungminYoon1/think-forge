# THINK FORGE — 수학·컴퓨터과학 문제은행

> 배포 단계 안내(2026-10-09): 로컬 검토 후 사용자의 공개 배포 승인을 받았습니다. 아래 LOCAL ONLY/NOT_RUN은 배포 전 검토 기록입니다. 승인 후 실제 공개 결과는 [통합 배포 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)의 최신 배포 절에서 따로 확인합니다.

[사이트 열기](https://hyungminyoon1.github.io/think-forge/)

은행 v2는 수학 8개·컴퓨터과학 8개 범주의 **48개 추론 문제군**을 제공합니다. 수학은 수능형 다단계 추론, 전공은 대학 시험형 연습을 목표로 자체 제작했습니다. 실제 수능 기출이나 공식 난이도 인증을 뜻하지 않습니다. 41개 자체 제작 문제군과 7개 출처 표시 번안 문제군을 구분합니다. 숫자·보기만 바꾼 경우나 단계 차이는 별도 문제군으로 세지 않습니다.

- 수학: 정수·나머지·계수, 방정식·함수, 함수·극값·교점, 도형·좌표, 확률, 논리·수열, 벡터·행렬, 미적분·최적화.
- 컴퓨터과학: 논리, 코드 추적, 그래프 알고리즘, 운영체제·메모리, 네트워크, SQL·함수 종속성, Git DAG, 점화식·DP·작업 DAG.
- 학습: 단계별 힌트·풀이·데이터 표. v1 오답의 기존 그래프·도형도 계속 복원.
- 10문제 도전: 단계별 20/25/30/40분. 추가 힌트 버튼은 비활성화. 종료 후 제출·건너뜀·미제출 10문제 전체의 내 답·정답·풀이·출처를 복습.
- 오답 복습: 틀린 조건을 그대로 재현하고 맞히면 복습 목록에서 제거.
- 경험치·레벨·범주별 기록, 오늘의 도전, JSON 기록 내보내기.
- 정답 중복 제출 방지, 빈 답 거부, 분수·동치 소수 처리. 수식 파서 없이 정수·유리수 또는 제공된 선택지를 입력합니다.
- 수학/전공 혼합에서는 각각 24개 문제군을 한 바퀴 돌기 전 같은 군을 재출제하지 않습니다. 단일 범주는 세 문제군을 순환합니다.

## 네 단계의 의미

첫 방문과 새 페이지 로드에서는 **수학 전체 혼합 · 4단계 복합 조건 독립 풀이**로 시작합니다. 첫 경험부터 복합 조건을 스스로 연결하도록 하는 운영 선택입니다. 1~3단계는 선택 메뉴에서 자유롭게 바꿀 수 있습니다. 초기 선택을 4단계로 정한 것이 수능·대학 시험 난이도 인증을 의미하지는 않습니다.

1. 단계 안내: 여러 조건을 연결하는 기본 추론에 풀이 출발점을 제시합니다.
2. 독립 추론: 같은 개념군의 기본 추론을 출발점 없이 풉니다.
3. 복합 조건 안내: 추가 제약, 정책 비교, 역추론, 증명 선택 등을 출발점과 함께 풉니다.
4. 복합 조건 독립 풀이: 복합 추론을 출발점 없이 수행합니다.

단계는 네 개의 공인 난이도 등급이 아닙니다. 1/2 및 3/4는 각각 안내 유무를 구분하며, 주된 수학적 복잡도 변화는 기본/복합 추론 사이에 있습니다. 생성 가능한 조건은 유한하고 일부 증명형 정답은 반복될 수 있습니다.

## 규칙과 저장 범위

정답 경험치는 단계에 따라 증가하고 오답에도 소량의 학습 경험치를 줍니다. 세션 점수와 누적 학습 기록은 구분합니다. 날짜 도전은 방문자의 로컬 날짜를 사용하며 은행 버전·범주·단계가 같아야 같은 문제입니다. 도전의 제출 정답률과 전체 10문제 정답 수를 따로 표시합니다. 미제출은 오답 기록·XP에 넣지 않습니다.

저장 키 `think-forge-v1`은 유지합니다. 버전 없는 기존 오답은 변경하지 않은 v1 생성기로 재현하며 새 오답에는 `bankVersion: 2` 및 혼합/단일 선택 범주를 저장합니다. 정답 복습은 해당 버전의 해당 조건만 제거합니다. 최대 200개에서 새 오답 추가를 멈추며 기존 오답을 자동 밀어내지 않습니다. 지원하지 않는 버전·형식은 복습 대상에서 제외하되 원본 기록과 JSON 내보내기에 보존합니다. 전체 삭제는 사용자가 기록 삭제를 확인했을 때만 수행합니다.

## 실행과 배포

Node.js 22.13 이상 (이번 검증 22.23.2), 런타임 외부 의존성 없음. SQL 검증에는 Node 내장 SQLite를 사용하며 Node 22에서 experimental 경고가 나올 수 있습니다. 실제 PostgreSQL 검증을 의미하지 않습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
