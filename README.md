# THINK FORGE — 수학·컴퓨터과학 문제은행

[사이트 열기](https://hyungminyoon1.github.io/think-forge/)

수학 7개 범주와 컴퓨터과학 7개 범주를 4단계로 연습합니다. 숫자·보기를 seed로 생성하고, 정답과 풀이도 같은 매개변수에서 계산합니다. 개념형 문항은 선별된 템플릿이므로 다시 나올 수 있습니다.

- 수학: 수와 연산, 방정식·함수, 함수 그래프·점 선택, 도형·좌표, 경우의 수·확률, 논리·집합·수열, 벡터·행렬.
- 컴퓨터과학: 진법·논리회로, 코드 실행 추적, 자료구조·알고리즘, 운영체제·메모리, 네트워크, 데이터베이스·SQL, Git·버전 관리.
- 차근차근 학습: 힌트, 풀이, 좌표·도형·SQL 표 시각화.
- 10문제 도전: 3분 제한, 힌트 없이 완주 결과와 정답률.
- 오답 복습: 틀린 조건을 그대로 재현하고 맞히면 복습 목록에서 제거.
- 경험치·레벨·범주별 기록, 오늘의 도전, JSON 기록 내보내기.
- 정답 중복 제출 방지, 빈 답 거부, 분수·동치 소수 처리. 그래프의 점은 클릭과 키보드로 선택 가능.

## 규칙과 저장 범위

정답 경험치는 난이도에 따라 증가하고 오답에도 소량의 학습 경험치를 줍니다. 세션 점수와 누적 학습 기록은 구분합니다. 날짜 도전은 방문자의 로컬 날짜를 사용하며 범주·난이도가 같아야 같은 문제입니다. 오답은 최대 200개 보관합니다. 이 콘텐츠는 연습용이며 공인 시험이나 전체 교육과정을 대신하지 않습니다.

## 실행과 배포

Node.js 22 이상, 런타임 외부 의존성 없음.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 loopback에서 `dist/`만 제공합니다. `main`에 푸시하면 고정 SHA Actions가 시험·정적 검사 후 `dist/`를 GitHub Pages에 배포합니다. 저장소 Pages의 배포 소스는 GitHub Actions입니다.

## 기록과 개인정보

기록은 이 브라우저에만 저장하며 삭제할 수 있습니다. 계정, 분석 도구, 외부 AI API, 클라우드 저장, 전체 사용자 랭킹은 구현하지 않았습니다. CSP가 런타임 외부 연결을 막습니다. 공개 저장소에 정답·게임 규칙이 포함되므로 시험/공식 경쟁 판정 시스템이 아닙니다.
